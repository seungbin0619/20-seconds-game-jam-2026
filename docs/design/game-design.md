# 게임 디자인

[`../prototype.html`](../prototype.html)은 방 하나짜리 원형이다. 이 문서의 확장 기획이 프로토타입보다 우선한다.

## 한 줄 요약

판마다 구조가 바뀌는 작은 집 어딘가에서 폰이 울린다. 소리를 따라 방을 찾고, 쌓인 물건을 치워 20초 안에 받는다.

## 잼 규칙에서 오는 제약

- 한 판은 20초다.
- **판은 서로 독립이다.** 이전 판의 방 상태, 결과, 보상이 다음 판의 게임플레이에 영향을 주면 안 된다.
- 판 사이에 남는 것은 보여주기용 **기록**뿐이다.

## 핵심 재미

- **소리가 유일한 단서다.** 방향, 거리, 덮임에 따른 먹먹함, 벽 너머의 먹먹함, 문 쪽에서 들려오는 소리로 위치를 좁힌다.
- **같은 판이 없다.** 집 구조, 방, 숨는 자리, 발신자, 변수가 매번 바뀐다.
- **결과 칭호와 기록**이 다시 하고 싶게 만든다.

## 한 판의 구조

```
시드 결정 → 무작위 요소 결정 → 집 생성 → 20초 플레이 → 결과(성공/실패, 발신자 반응, 칭호) → 기록 갱신
```

판의 모든 무작위는 시드 하나에서 나온다. 같은 시드면 같은 판이 나오므로 버그 재현에 쓴다.

## 상태 흐름

```
title ──시작──▶ playing ──폰 집기──▶ answer ──슬라이드 완료──▶ won
                  │                   │
                  └──── 시간 종료 ─────┴──────────────────▶ missed

won / missed ──다시 하기 또는 R──▶ playing (새 시드)
```

`answer` 중에도 타이머는 계속 흐른다. R은 `title`을 제외한 모든 상태에서 즉시 새 판을 시작한다.

## 무작위 요소

| 요소 | 내용 | 우선순위 |
|---|---|---|
| 집 구조 | 배치 틀(일자, ㄱ자, T자 등) 위에 방 2~4개 | 필수 |
| 방 종류 | 침실, 거실, 주방, 욕실, 드레스룸 | 필수 (3종부터 시작) |
| 가구 세트 | 방 종류마다 변형 1~2개 | 필수 |
| 숨는 자리 | 가구에 표시된 자리 중 한 곳에 폰. 다른 자리에도 물건 더미 | 필수 |
| 물건 | 더미 높이, 흩어진 물건 수, 종류 비율 | 필수 |
| 시작 위치 | 폰이 없는 방 중 한 곳 | 필수 |
| 발신자 | 발신자마다 고유 벨소리 | 필수 |
| 변수 | 판마다 0~1개 (아래 표) | 필수 |

생성 방식은 [`level-generation.md`](../architecture/level-generation.md)에 있다.

### 변수

| 변수 | 내용 | 우선순위 |
|---|---|---|
| 미끼 소리 | TV 속 전화벨, 알람시계, 태블릿 알림 같은 가짜 소리가 다른 곳에서 난다 | 필수 |
| 진동 모드 | 벨 없이 진동 소리와 물건 떨림만 난다 | 필수 |
| 정전 | 집 전체 또는 방 하나가 어둡다. 폰 화면 불빛이 단서 | 필수 |
| 닫힌 문 | 문 하나가 닫혀 있어 클릭해서 연다. 닫힌 문 너머는 더 먹먹하다 | 선택 |
| 배터리 부족 | 벨이 20초보다 일찍 끊긴다 | 선택 |
| 소음 | 욕실 환풍기나 빗소리가 벨을 가린다 | 선택 |

## 소리 설계

| 단서 | 동작 |
|---|---|
| 방향 | HRTF 3D 음향 |
| 거리 | 거리 감쇠 (`rolloff`) |
| 덮임 | 폰 위 물건 수가 많을수록 고음이 깎인다 |
| 벽 | 폰과 플레이어가 다른 방이면 사이의 벽 수만큼 더 먹먹해진다 |
| 문 쪽 소리 | 다른 방이면 소리가 **폰 방으로 가는 경로의 첫 문 쪽**에서 들린다 |

문을 지날 때 소리가 튀지 않도록 다음을 지킨다 (오디오 검증에서 확인).

- 거리는 문을 경유하는 경로 길이로 잰다. 문 앞에서 커졌다가 통과 후 작아지는 일이 없다.
- 문에서 `doorBlendRadius` 안으로 들어오면 방향이 문 쪽에서 폰 쪽으로 서서히 돌아가고, 벽 한 겹이 서서히 걷혀 문턱에서 다 걷힌다.

벽과 경로는 레이캐스트가 아니라 생성 시 만든 **방 그래프**로 계산한다.

## 규칙

| 항목 | 내용 |
|---|---|
| 판 준비 | 모든 숨는 자리에 물건 더미를 쌓고, 그중 한 자리의 맨 아래에 폰을 둔다 |
| 흩뿌림 | 방마다 바닥에 물건을 몇 개 흩뿌린다 |
| 안정화 | 시작 전에 물리를 90스텝 돌려 더미를 가라앉힌다 |
| 폰 집기 | 도달 거리 안, 화면 중심 레이와 폰의 거리 0.17m 이내, 사이에 가림막 없음 |
| 물건 던지기 | 조준한 물건을 시선 수평 방향으로 던진다. 좌우로 ±0.28 비율의 무작위 편차 |
| 바구니처럼 벽이 있는 곳의 물건 | 걸리지 않도록 전방 1.6 / 위 6.2로 띄운다 |
| 덮임 수 | 폰 기준 높이 -0.03~+1.1m, 물건 로컬 XZ 범위 + 0.05m 안에 드는 물건 수 |
| 진동 | 벨 한 주기의 절반마다 폰 반경 0.5m, 높이차 0.6m 안의 물건을 살짝 튀게 한다 |
| 폰 흔들림 | 덮인 물건이 0개일 때만 폰이 좌우로 진동한다 |
| 받기 | 옆으로 밀기 슬라이드를 끝까지 민다 |
| 실패 연출 | 카메라가 폰을 향해 돌아가고 폰 화면이 빨갛게 바뀐다 |

타이머는 **실제 시간**으로 줄어든다. 게임 시간 스케일이나 프레임 드랍 보정의 영향을 받지 않는다.

## 결과 칭호

그 판 안에서만 판정한다. 조건을 만족한 것 중 우선순위가 가장 높은 하나를 결과 화면에 표시한다.

| 칭호 | 조건 |
|---|---|
| Speedrunner | 3초 안에 받기 |
| Buzzer Beater | 0.5초 이하로 남기고 받기 |
| Sniper | 던진 물건에 맞은 더미에서 폰이 드러남 |
| Neat Freak | 한 번도 던지지 않고 받기 |
| Tornado | 물건을 15개 이상 던짐 |

## 기록

판 사이에 남는 유일한 데이터다. 게임플레이에는 영향을 주지 않는다.

- 저장 항목: 최고 기록(가장 빨리 받은 시간), 받은 전화 수와 놓친 전화 수, 만난 발신자, 얻은 칭호, 찾은 이스터에그
- 타이틀 화면에서 본다.
- Web에서는 `PlayerPrefs`가 브라우저 저장소(IndexedDB)에 저장되므로 브라우저마다 따로 남는다.

## 후순위: 숨겨진 요소

15일 범위 밖이다. 여유가 생기면 이 순서로 넣는다.

1. 희귀 발신자 (미래의 나, 산타 등 낮은 확률, 전용 벨소리와 문구)
2. 더미 속 숨은 물건 (리모컨, 지폐 등. 결과 화면에 "Also found" 표시)
3. 방 반응 (TV 맞히면 채널 변경, 바구니에 넣으면 "3-pointer!")
4. 희귀 폰 (플립폰은 받는 방식이 다름)
5. 고양이 (폰 위에 앉아 있거나 물고 이동)

## 튜닝 값 (`GameTuning`)

| 키 | 값 | 설명 |
|---|---|---|
| `duration` | 20 | 게임 길이(초) |
| `walkSpeed` | 3.2 | 걷는 속도(m/s). 여러 방 기준으로 재조정 필요 |
| `lookSpeed` | 0.0023 | 마우스 감도(rad/px) |
| `reach` | 3.1 | 손이 닿는 거리(m) |
| `throwForward` | 4.6 | 던지는 수평 속도 |
| `throwUp` | 3.6 | 던지는 위쪽 속도 |
| `throwCooldown` | 0.1 | 던지기 간격(초) |
| `clearCutoff` | 7000 | 덮이지 않았을 때 고음 한계(Hz) |
| `coveredCutoff` | 420 | 많이 덮였을 때 고음 한계(Hz) |
| `maxCovers` | 4 | 이 개수부터 가장 먹먹함 |
| `wallCutoffScale` | 0.5 | 벽 하나당 고음 한계 배율 (임시값, 폴리시 단계에서 조정) |
| `wallGainScale` | 0.8 | 벽 하나당 볼륨 배율 (임시값, 폴리시 단계에서 조정) |
| `minCutoff` | 200 | 덮임과 벽이 겹쳐도 고음 한계를 이 아래로 내리지 않는다(Hz) |
| `rolloff` | 2.2 | 거리 감쇠 |
| `doorBlendRadius` | 1.5 | 문에서 이 거리(m) 안이면 소리 방향과 벽 가림이 서서히 바뀐다 |
| `emitterFollowSpeed` | 6 | 소리 경로가 바뀔 때 따라가는 속도(1/s) |
| `ringGainStart` | 0.5 | 판 시작 시 벨 볼륨 |
| `ringGainEnd` | 1.2 | 시간이 다 됐을 때 벨 볼륨. 더 올리면 가까이서 소리가 깨진다 |
| `jiggle` | 0.55 | 진동 시 튀는 속도 |
| `slideNeeded` | 210 | 받기 슬라이드 거리(px) |
| `modifierChance` | 0.5 | 판에 변수가 붙을 확률 (잠정) |
| `roomCount` | 2~4 | 방 개수 범위 |

먹먹함 공식: `cutoff = max(minCutoff, clear × (covered / clear) ^ (min(1, covers / maxCovers) ^ 0.6) × wallCutoffScale ^ walls)`. `walls`는 문 근처에서 소수가 된다. `answer` 상태에서는 `clearCutoff`로 고정한다.
벨 볼륨: `lerp(ringGainStart, ringGainEnd, 경과시간/전체시간) × wallGainScale ^ walls`. 프로토타입(0.75→1.2)은 커지는 느낌이 약해 시작 볼륨을 낮췄다.

벽은 고음 깎기와 볼륨 감소를 함께 준다. 벨 기본음이 660~1480Hz라서 고음 깎기만으로는 벽 너머 느낌이 약했다 (오디오 검증에서 확인).

벽 효과를 조정할 때 알아둘 점:

- 고음을 깎으면 귀가 민감한 2~5kHz 대역이 빠져서 볼륨이 같아도 훨씬 작게 들린다. `wallCutoffScale`만 내려도 "작아지는" 느낌이 난다.
- 문 전환 구간(`doorBlendRadius` 1.5m)은 걷는 속도로 약 0.5초다. 전환이 급하게 느껴지면 이 값을 늘린다.
- 거리 감쇠(`rolloff` 2.2)도 크다. 경로 6.9m → 3.8m에서 볼륨이 약 2배가 된다.
- 테스트 씬(`Feature/Ringtone/Sandbox`)의 슬라이더로 Web 빌드에서 귀로 맞출 수 있다.

## 효과음

현재 효과음(던지기, 집기, 성공, 실패)은 프로토타입 소리를 옮긴 **임시**다. 폴리시 단계에서 확정한다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 걷기 |
| 마우스 (포인터 잠금) | 둘러보기 |
| 클릭 / Space | 물건 던지기, 폰 집기, 닫힌 문 열기 |
| 마우스 가로 이동 (`answer`) | 슬라이드 |
| R | 즉시 새 판 |

데스크톱 브라우저(키보드와 마우스)만 지원한다. 모바일 터치 조작은 만들지 않는다.

## 콘텐츠

### 발신자

발신자마다 벨소리가 다르다. 벨소리 구성은 오디오 검증 후 정한다.

| 이름 | 받았을 때 | 놓쳤을 때 |
|---|---|---|
| Mom | "Have you eaten yet?" | 1 new text: "Why aren't you picking up?" |
| Delivery Driver | "I'll leave it at your door." | "Missed delivery. Returning to sender." |
| Job Interview | "We'd like to offer you the position." | "We couldn't reach you. We've moved on to the next candidate." |
| Fried Chicken Place | "Your address didn't come through. Which building?" | Your chicken is getting cold. |
| Unknown Number | "Hello! We have a low-interest loan offer for you." | Probably nothing important anyway. |

### UI 문구

**게임 안의 모든 텍스트는 영어만 쓴다.** 프로토타입의 한국어 문구 대신 아래 문구를 기준으로 한다.

| 위치 | 문구 |
|---|---|
| 타이틀 | Missed Call |
| 타이틀 설명 | Your phone is ringing somewhere. Find it and pick up before it stops. |
| 조작 안내 | WASD: Walk / Mouse: Look around / Click: Throw items, grab phone |
| 시작 버튼 | Ring It |
| 타이틀 하단 | Headphones make the direction much easier to hear. |
| 플레이 힌트 | Follow the sound and clear the piles |
| 조준 라벨 | Throw / Grab phone / Open |
| 받기 화면 | Incoming call / Pick up! / Slide to answer |
| 성공 | Hello? / Answered in {0.0}s |
| 실패 | 1 Missed Call / Your phone was {0.0}m away |
| 재시작 | Try Again / Press R to restart |
| 기록 | Best / Answered / Missed / Callers / Titles (화면 구성은 UI 단계에서 정한다) |
